# NVIDIA Isaac Fundamentals

This chapter introduces you to NVIDIA Isaac, a comprehensive platform for developing AI-driven robotics applications. You'll learn about the core components of Isaac, its architecture, and how it fits into the broader robotics ecosystem.

## Learning Objectives

By the end of this chapter, you will be able to:
- Explain what NVIDIA Isaac is and its key components
- Understand the role of Isaac in AI-driven robotics development
- Differentiate between Isaac Sim and Isaac ROS and their respective use cases
- Set up an Isaac development environment
- Identify the key advantages of using Isaac for robotics applications

## Chapter Structure

This chapter is organized into the following sections:

1. [What NVIDIA Isaac Is](./what-is-isaac.md) - Understanding the Isaac platform and its components
2. [Role in AI-Driven Robotics](./role-in-robotics.md) - Isaac's position in the robotics ecosystem
3. [Isaac Sim vs Isaac ROS](./isaac-sim-vs-ros.md) - Comparing simulation and runtime environments
4. [Getting Started with Isaac](./getting-started.md) - Setting up your development environment
