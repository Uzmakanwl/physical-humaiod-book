# Module 3 - The AI-Robot Brain (NVIDIA Isaac™)

Welcome to Module 3 of the ROS 2 Educational Series, focused on advanced perception, navigation, and training for humanoid robots using NVIDIA Isaac. This module builds on the ROS 2 fundamentals from Module 1 and digital twin concepts from Module 2, introducing you to NVIDIA's powerful platform for AI-driven robotics.

## Learning Objectives

By the end of this module, you will be able to:
- Understand the fundamentals of NVIDIA Isaac and its role in AI-driven robotics
- Differentiate between Isaac Sim and Isaac ROS and know when to use each
- Implement perception and localization systems using Isaac ROS
- Apply Visual SLAM (VSLAM) concepts for robot navigation
- Leverage hardware-accelerated perception for efficient robotics applications
- Understand Nav2 integration with Isaac for humanoid navigation
- Implement simulation-to-real workflows for humanoid robots

## Prerequisites

Before starting this module, you should have:
- Completed Module 1: ROS 2 Fundamentals
- Basic understanding of robotics concepts
- Familiarity with simulation environments (covered in Module 2)
- Access to a system with NVIDIA GPU (recommended for practical exercises)

## Module Structure

This module is organized into three main chapters:

1. **NVIDIA Isaac Fundamentals** - Introduction to Isaac platform, architecture, and core concepts
2. **Perception & Localization with Isaac ROS** - Visual SLAM, hardware acceleration, and sensor integration
3. **Navigation & Training for Humanoids** - Nav2 integration, humanoid navigation, and simulation-to-real workflows

## Getting Started

Begin with the [NVIDIA Isaac Fundamentals](./isaac-fundamentals/index.md) chapter to establish a solid foundation before moving on to more advanced topics. Each chapter includes practical exercises and examples to reinforce your learning.
